## Branching

This repo always has multiple things in flight. **Always work on a feature branch** — never commit directly to `master`, even for small fixes.

Branch naming follows the global convention:
- `feat/short-description`
- `fix/short-description`
- `style/short-description`
- `docs/short-description`

Create the branch before making any changes. One logical concern per branch.
